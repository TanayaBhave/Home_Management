# Home Management

A self-hosted, offline-first chore planner for the household, installable on iPhone as a PWA.

- **Set up your home**: pick how many kitchens, bedrooms, bathrooms… and get rooms
  named "Bedroom 1", "Bathroom 2" with suggested chores.
- **Dirtiness meters**: each chore gets dirtier until it's due; slide to say how dirty
  it is right now. Rooms and the whole home show a % clean.
- **Today list**: overdue, due today and coming up, filtered by person. Tap the circle to
  mark a chore done (with undo).
- **Frequency & effort**: daily through every 6 months; effort sets the points (5 / 10 / 20).
- **Household + leaderboard**: assign chores, earn points, weekly/monthly/all-time scores.
- **Reminders**: Web Push daily summary plus optional per-chore reminder times, sent by
  your own server.
- **Sync** between phones through your home server (SQLite), last-write-wins.
